# 🚗 Vehicle Rental Platform

A modern and user-friendly **Vehicle Rental Platform** designed to make vehicle browsing and booking easier. This project provides a simple and attractive interface where users can explore available vehicles and view rental information.

## 🌐 Live Demo

**Visit Website:** https://vehiclerentalplatform.netlify.app/

## 📌 About the Project

The Vehicle Rental Platform is a frontend-based web development project created as part of my B.Tech CSE academic coursework.

The main objective of this project is to develop a professional-looking vehicle rental website that allows users to explore vehicles and interact with the booking interface.

## ✨ Features

- Modern and responsive user interface
- Attractive website design
- Vehicle browsing interface
- Vehicle rental information
- User-friendly navigation
- Interactive website elements
- Easy-to-use booking interface

## 🛠️ Technologies Used

- **HTML** – Website structure
- **CSS** – Styling and layout
- **JavaScript** – Interactive functionality

2. Open the project folder in Visual Studio Code.
3. Make sure all project files are in their correct locations.
4. Open `index.html` in your browser.
